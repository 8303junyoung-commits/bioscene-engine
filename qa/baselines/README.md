# Visual baselines

Canonical checkpoints are generated with a fixed 1440×1000 viewport and public or synthetic biology fixtures. Set `QA_UPDATE_BASELINES=true` only for an intentional design update. Deterministic runs never call Gemini; visual differences are evidence checkpoints for the optional Gemini reviewer and are not scientific validation.

Planned canonical figures: IL-18 simple receptor, IL-18 full signaling, bispecific 1+1, bispecific 2+1, and environment scene.
